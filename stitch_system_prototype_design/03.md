## 1. 目录

```text

  HomePage.tsx          总览
```

样本只放在根目录 `data`，不复制进 `src`。

## 2. 页面布局

壳层左侧 6 项：总览、资料归集、依据检索、文稿预审、审核办理、办件分析。顶栏是页面名和三个角色。

页头写工作台名称、验收角色，以及该页包含的原编号。当前身份不一致时，验收角色用提醒色。

总览只画 5 张卡。每张卡展开内部原编号，走到通过动作后打点。判定：

| 原编号 | 会话条件 |
| --- | --- |
| INF-01 | 已采集 |
| INF-02 | UP-01 与 UP-02 都已抽取 |
| INF-03 | 已归档 |
| INF-04 / INF-05 | 对应问法已出结果 |
| DOC-01～03 | 已检查文稿 |
| DOC-04 | 已复用 |
| DOC-05 | 已退回 |
| VIS-01 | 已核对 |
| VIS-02 | 已导出 |

「重置演示」清空会话并回到总览。

## 3. 资料归集

一页三块，纵向排列。

**今日归集。** 展示每日 07:30 和「手动采集」。采集前列表为空，点击约 0.7 秒后列出三个 JOB。可按来源、层级、主题、结果筛选。JOB-001 展开模拟原文。JOB-003「记录重试」只追加日志。

**文件抽取。** 两个模拟文件。抽取结果含标题、文号、核心内容、指标表。UP-02 文号处显示「待核」。点击原文位置高亮 `anchor`。完成后写入 `extracted`。

**资料库。** 顶部两张卡对照 KB-003 与 KB-005，可切换查看。按钮生成 KB-008 后变为「已归入 KB-008」。下方表格四个筛选：市级 + 现行看到 KB-003；被替代看到 KB-005；归档后内部文稿看到 KB-008；台账看到 KB-006。

KB-008 字段：

```text
id = KB-008
title = 内部文稿： + KB-005.title + （落档）
docNo = 内部-KB-008
category = 内部文稿
level = 本级
status = 内部
source = 版本切换落入
articles[1] = KB-005 第 2 条
```

## 4. 依据检索

检索框上方两个问法：「完整文号」「主题近义」。示例可一点即搜。

- 完整文号无结果时，提示使用示例 `演示协同〔2026〕07号`。命中后第一张卡标明「首条 · KB-003」。
- 主题近义的主区标题为「推荐」，只有 KB-003、KB-004，后者带「已替代」。次区标题为「替代关系」，放 KB-005。
- 两种结果的「查看原文」打开同一阅读器。「跳转到第 2 条」滚动到 `article-KB-003-2`。

## 5. 文稿预审

左栏公文纸，右栏一张问题单。问题单用三个小标题分组：文字、格式、合规。分组来自问题的 `kind`，不另做三个按钮入口。主按钮是「检查文稿」。

公文纸按 `drafts.json` 的 `parts` 渲染，锚点为 `typo`、`cite`、`time`、`scope`、`sign`。v1 落款显示「成文日期：未填写」。圆章文字为「演示专用」。

F-01 提供「采纳建议」，只改左侧缓冲。F-03、F-04 展开 `basis-compare.json`，并定位到 KB-003 第 2 条。政策层级筛选放在合规分组下面，作为依据来源。

## 6. 审核办理

## 7. 办件分析

上方核对表，下方趋势图，中间是 10 月核对卡。

表列：编号、街道、统计期、数值、单位、来源、三项结论。DATA-X01 单位格为「待补充」。「开始核对」后写出结论。「复用抽取」在 UP-01 未完成时提示回到资料归集；完成后两行结论为一致。手工录入行附在表底。

图默认两街道、2026-07 至 2026-10。两江 `#0c335c`，云桥 `#9f1d24`。纵轴 0 到 360。图下写数据来源、统计周期、计量单位。核对卡三块数字调用 `octoberCheck()`：296、234、530。

预览重复图、元数据和核对卡。CSV 表头为 `街道,统计期,办结件数,计量单位,数据来源`，内容是当前筛选后的入图行，UTF-8 带 BOM。

## 10. 彩排

重置后按工作台走，不要在菜单里找原编号。

1. 资料管理员进入资料归集。手动采集，看三种结果和 JOB-001 原文。抽取 UP-01、UP-02，看 2 条指标和「待核」。对照 KB-003、KB-005，归入 KB-008。
2. 撰稿员进入依据检索。先用完整文号跳到第 2 条，再切到主题近义，看 KB-003、KB-004 和「已替代」。
3. 进入文稿预审。检查文稿，依次点错字、成文日期、引用旧版、报送范围，打开条款。
4. 审核员进入审核办理。OA-001 看 4 条，OA-002 看复用，OA-004 看 0 条和「待人工复核」。再回 OA-003 退回，确认历史 4 条还在。
5. 撰稿员进入办件分析。表上看 8 条入图数据和 DATA-X01 的待补充，复用抽取看两行一致。图上读 296、234、530，预览后导出 CSV。
